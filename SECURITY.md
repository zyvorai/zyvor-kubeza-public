# Security policy

Please do not open a public issue for a vulnerability.

Report it privately using GitHub's "Report a vulnerability" feature on this repository (Security tab), or contact the Zyvor AI Labs organisation through its GitHub profile at https://github.com/zyvorai.

Include the affected version, steps to reproduce and the impact. We will acknowledge your report and keep you informed. Please allow reasonable time to respond before public disclosure.

Issues in upstream components, including K3s and Kubernetes, should also be reported to their maintainers.
